# Спартак · iOS — интерактивный прототип

Кликабельный HTML-прототип главного экрана iOS-приложения ФК «Спартак» для презентаций. Работает без сборки и зависимостей: только `index.html`, `app.js` и папка `assets/`. Анимации сделаны в духе iOS (пружинные кривые, glass-хедер, параллакс), а встроенный демо-сценарий сам «проходит» по экрану виртуальным пальцем.

## Запуск

Откройте `index.html` в браузере. Если шрифты или картинки не подгружаются при открытии через `file://`, поднимите локальный сервер:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

Лучше всего прототип выглядит в Chrome или Safari последних версий. Пружинные анимации построены на CSS `linear()`, а там, где он не поддерживается, используются `cubic-bezier`.

## Режимы отображения

| Режим | Как включить | Что видно |
|---|---|---|
| Десктоп | по умолчанию | Устройство 402×874 в рамке на тёмной сцене, панель управления снизу |
| Мобильный | автоматически на тач-экранах шириной < 760px или `?mobile` | Только приложение на весь экран, без рамки и панели |
| Принудительно десктоп | `?desktop` | Десктопный режим даже на телефоне |

Сайт можно добавить на экран «Домой» в iOS: мета-теги `apple-mobile-web-app-*` уже прописаны, и прототип откроется как отдельное приложение.

## Управление

| Клавиша | Кнопка | Действие |
|---|---|---|
| `Пробел` | Демо / Стоп | Запустить или остановить демо-сценарий |
| `C` | Корзина | Открыть или закрыть корзину |
| `M` | Меню | Открыть или закрыть меню |
| `R` | Сброс | Вернуть экран в исходное состояние |
| `←` / `→` | — | Листать слайды героя |
| `Esc` | — | Закрыть меню или корзину |

Клавиши работают и в русской раскладке (`С`, `Ь`, `К`). С мышью можно делать то же, что пальцем: drag-скролл с инерцией и свайпы по каруселям.

### Демо-сценарий

Функция `demo()` в `app.js` проходит такие шаги: слайдер героя → билеты (свайп и пагинация) → добавление в корзину → турнирная таблица (переключение лиги) → раскрытие карточек команд (закреплённый блок) → карусель абонементов → прокрутка до конца и обратно → меню → закрытие корзины свайпом вниз. Любое ручное действие останавливает демо.

## Структура

```
index.html   разметка всех секций + все стили (токены из Figma в :root)
app.js       вся логика: пружины, свайпы, карусели, корзина/меню, демо, HUD
assets/      SVG и PNG из Figma, fonts.css + fonts/ (Golos Text, Montserrat)
ref/         референсные скриншоты макетов (не используются страницей)
```

### Секции экрана (сверху вниз)

Hero-слайдер (`#hero`), сторис (`#stories`), ближайший матч и билеты (`#matchsec`), вход (`#loginsec`), реклама (`#adsec`), турнирная таблица (`#tablesec`), команды клуба (`.teams-sec`), медиа, абонементы (`#abo`), мерч и остальные блоки. Меню (`#menu`) и корзина (`#cartbar`) появляются из-под главного блока (`#main`).

### Как устроен `app.js`

Весь код лежит в одной IIFE и разбит на блоки с заголовками вида `/* ───── название ───── */`:

- **пружины**: `spring(zeta, cycles)` генерирует `linear()`-кривую затухающих колебаний, итог пишется в CSS-переменные `--spring` и `--spring-soft`;
- **режим и масштаб**: `fit()` подгоняет устройство под окно; множитель `S` учитывается во всех расчётах координат указателя;
- **логотипы**: составные SVG из Figma собираются по процентным `inset`;
- **`makeDiamonds`**: ромбики-пагинация, общая для героя, билетов и абонементов;
- **`swipeable`**: общий горизонтальный свайп (мышь и тач), вертикаль отдаётся скроллу;
- **таблица, команды, абонементы, билеты**: у каждого блока своя секция;
- **главный блок**: `setState` анимирует переход между состояниями обычный / корзина / меню;
- **демо-сценарий**: `tap`, `swipeX`, `swipeScroll` эмулируют касания через синтетические `PointerEvent` и двигают индикатор пальца `#touch`.

Для отладки из консоли доступен `window.__app` с функциями `openCart`, `closeCart`, `openMenu`, `closeMenu`, `demo`, `resetAll`, `heroGo(i)` и `ticketGo(i)`.

## Правки

- **Цвета и шрифты** задаются токенами в начале `<style>` в `index.html` (`--red`, `--ink`, `--font`, `--display`…). Фирменные `TT Norms Pro` и `FCSM` указаны первыми в стеке: если они установлены в системе, браузер их подхватит, а если нет, возьмёт `Golos Text` / `Montserrat` из `assets/fonts`.
- **Данные таблицы** хранятся в константах `LG` и `TABLES` в `app.js`.
- **Тайминги демо** задаются вызовами `wait(...)` и длительностями в `demo()`.
- **Новый шаг демо**: перед каждым следующим шагом проверяйте `if (!alive(my)) return;`, иначе остановка и сброс сработают некорректно.
